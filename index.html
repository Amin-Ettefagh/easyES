The project idea

Future companies will not be only human teams or only AI agents. They will be mixed execution systems where work can move between people, agents, tools, services, review gates, and automated quality loops.

01

Model the organization

Represent companies, departments, roles, capabilities, human actors, AI actors, tools, policies, budgets, and permissions.

02

Design the work

Create workflow graphs with typed nodes, conditional edges, retries, approvals, evaluations, artifacts, and terminal states.

03

Run and improve

Execute each workflow, record every event, inspect artifacts, route model calls, and feed QA failures back into bounded fixes.

What easyES is

It is not just a chatbot, agent builder, or automation clone. easyES is a control plane for organizational execution where domain concepts stay separate and observable.

  • Role != Actor != Agent != Model. People, jobs, AI workers, and provider models stay cleanly separated.
  • Workflow != Project != Execution. Designs, workspaces, and runtime histories are different objects.
  • Evaluation != Execution. Quality checks can drive decisions without hiding the work trail.
  • Tool != Connector. Internal actions and external integrations can evolve independently.

Architecture

The repository is a production-shaped foundation demo: a Django modular monolith, a Next.js control room, PostgreSQL persistence, seeded data, and an offline model provider for deterministic local runs.
